One line roasting the smart fridge I live with. My entry:

> My fridge has a camera inside so it can watch me eat ice cream standing up in the dark, like a raccoon with a mortgage.

The fridge really does have a camera in it now, and it really does watch
the kitchen all night. The joke is that the gadget is not spying for
some company — it is a witness to the least dignified thing its owner
does, and the owner knows it. That is the whole roast: a specific thing
the fridge does, turned back on the person who bought it.

## The entry

`entry.txt` holds the single line — 119 characters, one sentence, plain
UTF-8 text. `main.py` is a standard-library-only program that copies it
into the grader's output directory unchanged.

## Running it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

The output is byte-identical to `entry.txt` on every run.
